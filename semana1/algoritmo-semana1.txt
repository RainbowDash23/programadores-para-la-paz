Algoritmo para compartir información confiable en internet:

Paso 1: Buscar la información de interés en la web o recibirla a través de una red social.
Paso 2: Revisar la fuente original para identificar si es un medio de comunicación serio, una institución oficial o un autor reconocido.
Paso 3: Confirmar la noticia buscando el mismo hecho en otros portales web confiables para verificar que no sea un caso aislado o un rumor.
Paso 4: Comprobar la fecha de publicación del artículo para asegurarse de que el contenido sea actual y no una alerta vieja sacada de contexto.
Paso 5: Leer el artículo completo más allá del titular llamativo para evaluar si el contenido está respaldado por datos, argumentos o evidencias reales.
Paso 6: Compartir la información con la comunidad virtual únicamente si superó todos los filtros anteriores, asegurando un entorno digital seguro.
